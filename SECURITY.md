# Security

Report reproducible vulnerabilities privately through GitHub Security Advisories
when available. Otherwise request a private channel from a maintainer without
posting exploit details. Include the affected revision, expected/actual behavior,
and a minimal synthetic reproducer. No formal audit or response SLA is claimed.

Keep private keys, wallet credentials, signed transaction payloads, SERVICE_TOKEN,
environment files, databases, and customer records out of commits and logs.
Use synthetic data and Testnet funds for verification. Network success alone
does not verify payment claims; incomplete settlement evidence remains pending.
Read README.md for implemented boundaries and configuration.
